# Repo Setup (Windows)

1. Navigate to : SOLIDWORKS Installation, "\SOLIDWORKS Corp\SOLIDWORKS\api\redist"
  - By default, SW Installation is in "C:\Program Files\"
2. Copy these three files into the ./interops/ directory :
  - SolidWorks.Interop.sldworks.dll
  - SolidWorks.Interop.swconst.dll
  - SolidWorks.Interop.swpublished.dll

# Running
To run app, run :
`dotnet run --project .\src\App\App.csproj`
